# EMfinder

전자음악 장르를 탐색하고 SoundCloud 플레이리스트로 들어보는 Next.js 웹페이지입니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 여세요. SoundCloud 임베드의 재생·일시정지 상태와 LP 회전 애니메이션이 동기화됩니다.

## 빌드 및 배포

```bash
npm run build
npm run start
```

Vercel에서 이 저장소를 불러오면 Next.js 기본 설정으로 배포할 수 있습니다. SoundCloud 플레이리스트는 장르별 공개 URL을 사용하며 별도 API 키는 필요하지 않습니다.
