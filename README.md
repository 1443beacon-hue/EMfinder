# EMfinder

전자음악 장르를 탐색하고 Spotify 플레이리스트로 들어보는 Next.js 웹페이지입니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 여세요. Spotify 임베드 재생 상태와 LP 회전 애니메이션은 Spotify 플레이어가 로드된 뒤 동기화됩니다.

## 빌드 및 배포

```bash
npm run build
npm run start
```

Vercel에서 이 저장소를 불러오면 Next.js 기본 설정으로 배포할 수 있습니다.
